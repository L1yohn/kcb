# 📚 大学课程表查询系统 (手机移动端优化)

根据您的课程表定制开发的现代化课程表 Web 系统，专为**手机端、平板与电脑**自适应打造。

---

## 🚀 快速启动与访问

### 方式一：手机与电脑同 Wi-Fi 访问 (推荐)
1. 双击运行目录下的 **`start.bat`** (或在终端运行 `node server.js`)。
2. 电脑将自动打开浏览器；终端将显示局域网访问地址（如 `http://192.168.x.x:8080`）。
3. 手机连接同一 Wi-Fi，在手机浏览器中打开该地址，或在网页右上角点击 **📱 图标** 扫码直接查看！

### 方式二：电脑直接双击打开
- 直接在文件管理器中双击 **`index.html`**，无需启动任何服务器，支持 100% 离线运行！

---

## ✨ 核心功能亮点

1. **📅 今日日程 (Today View)**：
   - 自动识别当前周次与今天星期，高亮展示今日课程、教室、授课老师与节次时间。
   - 顶部提供周一至周日快捷切换按钮。

2. **🗓️ 周课表网格 (Weekly Grid View)**：
   - 顶部支持滑动切换第 1 周至第 20 周。
   - 智能识别单周/双周及停课周次（如第5周停课、第7-8周心理健康等）。
   - 支持一键切换「仅看本周有课」与「显示全部课程」。

3. **🔍 课程检索与分类 (Search & List)**：
   - 实时搜索课程名称、教室、任课教师、排课规则。
   - 支持按「机房实验课」、「专业必修/选修」、「通识必修」、「本周有课」快捷筛选。

4. **📥 一键导出手机日历 (.ics)**：
   - 在「设置同步」页面点击「导出手机日历文件 (.ics)」。
   - 支持一键导入苹果 iOS 日历、华为、小米、OPPO、vivo 等安卓系统日历，享受上课前 20 分钟系统级弹窗提醒。

5. **📲 添加到手机主屏幕 (PWA)**：
   - 在手机 Safari 或 Chrome 浏览器中，点击「分享/菜单」➔「添加到主屏幕」，即可生成桌面独立 App 图标，全屏无边框使用。

6. **🌓 深色/浅色主题自由切换**：
   - 点击右上角 🌓 图标即刻切换现代暗黑主题与清新浅色主题。
